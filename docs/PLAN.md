# مصروفي — الخطّة

حالة المشروع (2026-10-19): **النواة جاهزة** — السيرفر وواجهة الويب للحسابات والعمليات والتصنيفات والميزانيات والتقارير والأسرة. التفاصيل والباقي في [`STATUS.md`](STATUS.md)، والمسارات في [`API.md`](API.md).

## الفكرة
تطبيق مصروفات شخصية وعائلية كامل للسوق المصري: ويب + موبايل + ديسكتوب. المطلوب جودة «شغل حقيقي». المكدّس: HTML/CSS/JS + React + Node + Express + MySQL.

## نطاق مقترح (يحتاج مراجعة صاحب المشروع قبل التثبيت)
- حسابات (نقدي، بنك، محفظة، بطاقة) وعمليات (دخل ومصروف وتحويل بين الحسابات) وتصنيفات.
- ميزانيات شهرية بالتصنيف مع تنبيه قبل التجاوز.
- فواتير وأقساط متكرّرة وتذكيرات، وأقساط (تقسيط) بجدول سداد.
- أهداف ادخار وديون (لي/عليّ) وجمعيات (الجمعية المصرية بدورها وأدوارها).
- أسرة (household): أفراد بصلاحيات، مصروف الأبناء، حسابات مشتركة.
- تقارير وصافي الثروة وتصدير/استيراد CSV، وتأمين ثنائي اختياري، وإشعارات.

## البنية والأعراف (نفس نُزُل)
- مجلدات `server/` و`client/` (لوحة ويب) و`mobile/` (واجهة لمس بـ Capacitor) و`desktop/` (Electron) و`docs/`.
- البورتات: السيرفر **4020**، الويب **5190**، الموبايل **5191**.
- كود بنفس أسلوب نُزُل: تعليقات عربية، ESM، Express 4 + mysql2 + Zod، فحص البيئة عند الإقلاع، ردود `{success, data}`، بلا بيانات تجريبية.
- المال أعداد صحيحة بالقروش، التواريخ `YYYY-MM-DD`، نفس نموذج المصادقة (JWT قصير + refresh دوّار).
- أنموذج عزل البيانات: `households` بدل `organizations` (كل المستخدمين داخل أسرة).
- راجع `Nozol/docs/STATUS.md` و`Nozol/server/src` كمرجع للبنية قبل البدء.
